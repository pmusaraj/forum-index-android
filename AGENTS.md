# Related repositories

This repository, `pmusaraj/forum-index-android`, is the Android app for Forum Index.
Coding prompts often refer to these companion repositories:

- [`pmusaraj/forum-index`](https://github.com/pmusaraj/forum-index): the backend.
- [`pmusaraj/forum-index-ios`](https://github.com/pmusaraj/forum-index-ios): the equivalent iOS app, a reference for app behavior and feature parity.

Local checkouts are often in sibling folders named `forum-index` and
`forum-index-ios`. Check those locations when a task refers to the backend or iOS
app. When working in a Git worktree, also check alongside the primary Android
checkout (located with `git worktree list`); do not assume companion repos are
siblings of the worktree itself. Verify paths exist before using them.
